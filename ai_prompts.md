## 2. AI Prompting & Constraint Strategy
- I personally have not used AI much, so this AI strategy will likely change over time. This will likely be a more iterative approach to designing methods instead of the program wholesale, as I want to gather experience on how LLMs generate their code.
- This may be compared/contrasted with a larger prompt to develop larger sections of the code, to see how the LLM (likely Claude) designs a larger problem based on a more descriptive prompt.
  
## Prompt Format:
-Goal: What we're trying to achieve with this prompt/code, the purpose.
-Context: What existing information can be used to develop this prompt. This may include my state machine diagram, or planning documentation for the specific methods that we're prompting for, etc. 
-Constraints: Requirements for the program such as the protocol, JSON format, etc. 
-Output: Output must be specific and defined to allow it to fit within the scope of the program.
